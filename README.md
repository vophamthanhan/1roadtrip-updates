# 1roadtrip-updates

Public update feed for **1Roadtrip Extension**.

Chrome reads these files from GitHub Pages:

- https://vophamthanhan.github.io/1roadtrip-updates/updates.xml
- https://vophamthanhan.github.io/1roadtrip-updates/1roadtrip-extension.crx

This repository is only the hosted package. Do not put `extension.pem` here.

After the first install (Chrome Web Store or Group Policy), Chrome checks `updates.xml` when it starts and installs a newer CRX automatically.
